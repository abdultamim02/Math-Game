Math Game for Finding Roots of Polynomial Equations
- Coded and implemented a math game in C and MIPS Assembly centered around finding the roots of polynomial equations. The game comprises seven progressively challenging questions, requiring players to solve equations with only two attempts.
- Implemented a navigational map within the MIPS Assembly program to dynamically direct and track the player's progress. This map serves as a visual representation, aiding players as they navigate through the different questions.
- The MIPS program generates sounds that correspond to the player's answers, effectively recognizing correct and incorrect answers. Additionally, unique sounds accompany the celebration of successfully completing the game along with the prize.
